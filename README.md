G-Haz is a geospatial web application for exploring natural hazards around a selected U.S. location. Built with React, TypeScript, the ArcGIS Maps SDK for JavaScript, and a Python API, it combines historical events, authoritative hazard zones, and regional loss estimates in an interactive map and source-linked report. The application identifies where assessment is supported, where coverage is incomplete, and where building-specific risk cannot be estimated from the available data.
